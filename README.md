# Körvis

Kanal görüntüleme (CCTV) kayıt, raporlama ve proje yönetimi programı.

## Kurulum

Son sürümü **[Releases](https://github.com/mustafaycg-beep/korvis-surumler/releases/latest)** sayfasından indirin: `Korvis_Kurulum_<sürüm>.exe`

- Windows 10 / 11, 64 bit
- Kurulu Körvis yeni sürüm çıktığında açılışta haber verir ve güncellemeyi kendisi indirir.
- Güncellemede projeleriniz, kayıtlarınız ve lisansınız korunur.

Program lisanslıdır. Lisans ve destek için: mustafaycg@gmail.com
